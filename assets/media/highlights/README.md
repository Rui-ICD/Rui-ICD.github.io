# 获奖照片

DAAD 领奖照片放在这个文件夹，命名为：

```text
daad-2022.jpg
```

完整位置：

```text
E:\GithubPage\Rui-ICD.github.io\assets\media\highlights\daad-2022.jpg
```

照片加入后，会自动出现在 **Highlights → Awards & scholarships** 的 DAAD Scholarship 条目中。完整显示，不裁剪领奖台或人物，点击可打开大图。未加入时，该条目先显示文字。

如果原图是 PNG 或 WebP，保持原格式，然后在 `data/awards.yaml` 中修改 `image` 的文件后缀。

2021 年的 Academic Distinction Scholarship 和 Women in STEM Scholarship 没有照片，按文字条目显示，不需要占位图。奖项名称、年份、学校和图注都在 `data/awards.yaml` 中修改。

四张会议活动照片仍放在 `assets/media/activities/`，不需要移动；它们现在显示在 **Highlights → Conferences & talks**。
