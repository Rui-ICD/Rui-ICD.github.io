# 实习照片

将 MediaTek 实习照片放在这个文件夹，文件名为：

```text
mediatek-2022-2023.jpg
```

完整路径：

```text
E:\GithubPage\Rui-ICD.github.io\assets\media\experience\mediatek-2022-2023.jpg
```

加入照片后，首页的 **Industry experience** 区域会自动显示图片。没有照片时，显示公司、岗位和起止月份，不留空白图片框。照片完整显示，不裁剪；点击可以打开大图。

如果照片是 PNG 或 WebP，把原格式的文件放进来，然后在 `data/authors/me.yaml` 的 `experience` 条目中修改对应的路径后缀。例如：

```yaml
image: media/experience/mediatek-2022-2023.png
```

实习信息也在同一个条目中：MediaTek、RF / Analog Intern、2022 年 7 月至 2023 年 4 月。`start` 和 `end` 使用 `YYYY-MM`，`period` 是图片下面显示的日期。
